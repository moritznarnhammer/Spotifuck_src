# Installing Spotifuck in Firefox

## Requirements
Firefox 58 or newer.

## Steps

1. Download the `.xpi` file you received.
2. Open Firefox and go to `about:addons` (or Menu → Add-ons and Themes).
3. Click the gear icon ⚙ and choose **Install Add-on From File…**
4. Select the `.xpi` file and click **Open**.
5. Click **Add** when Firefox asks for confirmation.

The extension is now active. No restart required.

## Verify it's working
Open [open.spotify.com](https://open.spotify.com) — ads should be blocked automatically.

## Uninstall
Go to `about:addons`, find **Spotifuck**, and click **Remove**.
